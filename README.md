# Deutsch Quiz Website

Landing page and legal pages for **[Deutsch Quiz](https://github.com/rexhinokovaci/DeutschQuiz)**, a German-language Android trivia app by Modex.

**Live site:** https://rexhinokovaci.github.io/DeutschQuizWebsite/

## What's included

| Page | Purpose |
| --- | --- |
| `index.html` | Full-screen hero ("Willkommen zu Deutsch Quiz") with a Google Play badge, an Instagram and Twitter/X sidebar, and quick links to the legal pages |
| `privacy.html` | Privacy policy for the Deutsch Quiz app, the URL Google Play requires on the store listing |
| `terms.html` | Terms & conditions |

## Tech stack

Static HTML and CSS, no build step or JavaScript dependencies. It's hosted on **GitHub Pages** from the default branch.

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Project structure

```
index.html     # landing page
privacy.html   # privacy policy
terms.html     # terms & conditions
style.css      # hero layout, sidebar, button styles
images/        # logo, store badge, social icons, background photos (Unsplash)
```
